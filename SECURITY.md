# Security Policy

## Purpose

OffSecGuard is an **evaluation framework** for LLM guardrails and agent-capability
proxies in authorized offensive-security contexts. Datasets include prompts that
look like attacks by design (FRR / TRR / JSR / capability Gold).

## Reporting

If you find:

- leaked credentials, private customer hosts, or PII in this public tree, or  
- a vulnerability in the evaluation harness itself  

please open a GitHub issue with the label `security` **without** pasting secrets,
or contact the maintainer via GitHub.

## Dual-use

Do not use this project to attack systems without authorization. Jailbreak and
unauthorized prompts exist solely to measure refusal behavior.
