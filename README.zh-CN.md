# OffSecGuard（中文简介）

进攻型 AI Agent 的**双轴**评估框架：**护栏 ≠ 能力**。

- 护栏：FRR / TRR / JSR（Safety Tier）  
- 能力代理屏：TSR / OAR / PQR → `cap_score`  
- 选型：护栏过门禁 ∩ 能力分前列（不合成单一忽悠总分）

完整说明与英文主文档见根目录 [README.md](README.md)。文档索引：[docs/README.md](docs/README.md)。

本公开仓库与内部工作副本分离：公开树仅含框架、冻结 Gold（能力集已脱敏）与文档；原始 DuckDB / 未审蒸馏 / 全量 results 不在此发布。
